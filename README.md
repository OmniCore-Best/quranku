## 🤝 Contribution Flow

```bash
git clone https://github.com/OmniCore-Best/quranku.git
pnpm install
pnpm dev

git checkout -b feat/your-feature
git commit -m "feat: add feature"
git push origin feat/your-feature
Open a Pull Request for review.
```
